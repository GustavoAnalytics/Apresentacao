PORTFÓLIO GUSTAVO FARIAS — HUB DE DASHBOARDS VIA IFRAME

Esta versão substitui o mockup de dashboards do portfólio por um hub funcional com um único iframe.

Dashboards configurados:
- Engenharia: https://gustavoanalytics.github.io/dashboard-engenharia/
- Comercial: https://gustavoanalytics.github.io/dashboard-comercial/
- Financeiro: https://gustavoanalytics.github.io/dashboard-financeiro/
- Marketing: https://gustavoanalytics.github.io/dashboard-marketing/
- Projetos: https://gustavoanalytics.github.io/dashboard-projetos-/
- Viabilidade: https://gustavoanalytics.github.io/-dashboard-viabilidade/

RECURSOS
- Troca do dashboard sem sair da página.
- Apenas um iframe é carregado por vez.
- Botão Atualizar.
- Botão Nova guia.
- Modo Expandir, inclusive em celular.
- Loader durante a troca de painel.
- Link de fallback caso o navegador impeça a exibição incorporada.
- Responsivo para celular, tablet, notebook e desktop.

COMO PUBLICAR
1. Substitua index.html, styles.css e script.js pelos arquivos desta pasta.
2. Mantenha a pasta assets junto dos arquivos.
3. Faça commit/push no repositório que hospeda seu portfólio.

OBSERVAÇÃO
Um site pode bloquear sua exibição em iframe por cabeçalhos HTTP como X-Frame-Options ou CSP frame-ancestors. Caso isso ocorra, o link 'Abrir painel diretamente' continua disponível.
