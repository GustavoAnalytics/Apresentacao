PORTFÓLIO EXECUTIVO — GUSTAVO FARIAS
Versão responsiva v2

Arquivos:
- index.html: apresentação principal
- styles.css: design completo + responsividade
- script.js: navegação, dashboards, calculadora e efeitos
- assets/: fotografias utilizadas na apresentação

RESPONSIVIDADE
O layout foi otimizado para:
- celulares pequenos (até 350 px)
- celulares convencionais (360–430 px)
- tablets em retrato (741–899 px)
- tablets em paisagem / notebooks compactos (900–1199 px)
- notebooks e desktops (1200–1599 px)
- monitores grandes (1600 px ou mais)
- telas com pouca altura, como notebooks 1366x768
- celular em modo paisagem

AJUSTES INCLUÍDOS
- tipografia fluida com clamp()
- espaçamento adaptativo por largura e altura
- grids que mudam de 2/3 colunas para 1 coluna quando necessário
- dashboards com abas roláveis no celular
- imagens com proporção e altura responsivas
- cards sem alturas fixas em telas pequenas
- botões com área mínima adequada para toque
- inputs com 16 px no celular para evitar zoom automático no iPhone
- suporte a safe area em aparelhos com notch
- scroll-snap desligado em telas menores para uma navegação natural
- animações ajustadas para seções maiores que a tela
- canvas otimizado para reduzir uso de CPU/GPU no mobile
- suporte a prefers-reduced-motion
- layout de impressão mantido em formato executivo

COMO ABRIR
Abra index.html em um navegador moderno. Não é necessário instalar dependências.

COMO PUBLICAR
Envie todo o conteúdo desta pasta para a mesma pasta pública do seu servidor/hospedagem, mantendo a estrutura assets/.
